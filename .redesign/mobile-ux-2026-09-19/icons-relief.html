Icônes avec relief : 4 pistes pour le menu

Même menu, quatre traitements. Le bouton Réglages grossit dans les pistes B à D. Icônes chargées en ligne (Iconify, jsDelivr) : il faut du réseau pour voir le draft.

A · Actuel. Phosphor « regular », trait fin gris. Propre mais plat.

B · Phosphor Duotone. La même famille que l'app, poids « duotone » : un second ton translucide donne du volume. Zéro nouvelle dépendance, mêmes formes, changement de chemins SVG seulement.

C · Tuiles iOS. Chaque icône dans une petite tuile en dégradé, comme les Réglages d'iPhone ; une couleur par thème rend les dossiers reconnaissables d'un coup d'œil. Pur CSS autour des icônes existantes.

D · Objets 3D. Fluent Emoji 3D de Microsoft (licence MIT) : de vrais petits objets en relief (dossier, mémo, bulle, engrenage). Le plus « fun », mais ce sont des PNG, pas des icônes teintables ; à réserver aux dossiers et aux Réglages.

Écartées : Glass Icons (Font Awesome restylé, CC BY 4.0 avec attribution obligatoire, dépôt tout jeune), Solar bold-duotone (CC BY 4.0, attribution visible obligatoire), icônes 3D WebGL (trop lourdes pour des listes).
