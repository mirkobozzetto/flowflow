C3 Lance la démo. Bulle utilisateur qui pousse depuis le coin, ligne d'état qui raconte (« Recherche dans tes notes… », « 3 notes trouvées, je lis… », « 2 notes retenues »), réponse révélée mot à mot, puis l'accordéon de sources existant qui glisse dessous, et les actions (copier, enregistrer) en fondu. Rien de nouveau dans la structure : ce sont les blocs actuels avec un ordre d'apparition.

Logique partagée note / chat

Une seule capsule vocale (états : enregistre, transcrit, relit, envoyé) montée dans les deux barres. Dans la note, « relire » affiche le texte dans la capsule et la flèche ajoute à la note ; dans le chat, « relire » pose le texte dans le champ et la flèche envoie. Même fond sombre que la pilule d'enregistrement actuelle (bg-stone-900), même orange pour l'action principale, même courbe --ease-soft.

Le popover « + » est lui aussi partagé : sections Agents, Outils, Connecteurs ; la note n'affiche pas Outils (pas de recherche web sur une note), comme aujourd'hui.
