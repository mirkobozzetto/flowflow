## Screenshots

iPhone only (the app is not an iPad app). One set per locale, 1320 x 2868
(6.9") from the iPhone 17 Pro Max simulator, or 1284 x 2778 (6.5").
Smaller sizes are scaled from these by Apple.

1. The note list: titles, tags, themes
2. Composer with the voice capsule recording
3. A note: AI title, tags, theme
4. Chat answering with tappable sources
5. Menu open under the sliding card: themes

Left out: the `+` menu (a demo store has no agent or connector installed,
so it reads "0 installed") and the native "…" menu (a headless simulator
cannot open it). Take them on the phone if wanted; 6.1" iPhone 16 captures
are resized to 1284 x 2778.

Demo data only: no personal notes, names or keys on screen.

```bash
# Demo stores (7 themes, 7 notes, one chat with sources), per locale
cargo run --example demo_store -- /tmp/flowflow-demo-en.db en
cargo run --example demo_store -- /tmp/flowflow-demo-fr.db fr

# Simulator build (the rustup toolchain must come first on PATH: the
# Homebrew rustc has no iOS simulator target)
export PATH="$HOME/.rustup/toolchains/stable-aarch64-apple-darwin/bin:$PATH"
make restore-ios-toml
set -a && . ./.env && set +a && IPHONEOS_DEPLOYMENT_TARGET=16.0 dx build --platform ios

# Boots the iPhone 17 Pro Max, installs the build on the demo store, sets
# a 9:41 status bar and sets every slot up through a debug-only watcher
scripts/capture-screenshots.sh en /tmp/flowflow-demo-en.db
scripts/capture-screenshots.sh fr /tmp/flowflow-demo-fr.db
```

Output: `screenshots/2.1.0/<lang>/NN.png`, ready for the 6.9" slot.
Xcode here ships no Simulator window: the run is headless, no taps needed.

## What's New - App Store, English

```
A new way to capture

One composer for notes and chat. Type, or tap the mic: a voice capsule
records, transcribes and puts the text back where you were typing. If a
transcription fails, retry without losing the audio.

The menu, under your notes

Your notes slide aside like a card to reveal the menu. Swipe from anywhere
to open it. Themes can be searched, every folder starts open, and the ones
you close stay closed.

Liquid Glass on iOS 26

Menu, chat, new note and options buttons use native Liquid Glass. Options
menus are the system ones: press, slide to an action, release.

Tools at hand

One + menu in notes and chat gathers tools, agents and connectors, each
with its live connection state and its product icon.

Agents you control

Installed agents are verified and pinned. Every capability is checked
against its owner, and every action waits for your confirmation.

Your account

The account screen shows your linked devices and Premium. A new welcome
screen introduces notes, collaboration and Hermes.

Also fixed

Deleting a note always completes, even if you close its menu. Copy or share
a single note inside a thread with a long press.
```

## GitHub release notes - macOS v2.1.0

Paste over the auto-generated notes after `make release`.

```markdown
## FlowFlow 2.1.0 for Mac

**Opens normally now.** The DMG is signed with a Developer ID and notarized
by Apple: no more right-click > Open on first launch.

**Dictation fixed for DMG installs.** Builds from the DMG could not reach the
microphone. They can again.

### New
- One composer for notes and chat, with a voice capsule that records,
  transcribes and hands the text back where you were typing
- Theme search in the sidebar and the title picker; folders you close stay
  closed across restarts
- One `+` menu in notes and chat: tools, agents and connectors, with live
  connection state and product icons
- Scoped agents: verified, pinned packages, every action confirmed first
- Account: linked devices and Premium on the account screen

### Fixed (from the iOS 2.0.2 and 2.0.3 patches)
- Deleting a note always completes, even after its menu closes
- Copy and share a single note inside a thread (right-click)
- Navigation, note controls and visual consistency

Apple Silicon only. Download `FlowFlow-macos-arm64.dmg`, drag FlowFlow to
Applications.
```
