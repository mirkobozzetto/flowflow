# Release 2.1.1

| | Previous | This release |
|---|---|---|
| iOS (App Store) | 2.0.2 live since 2026-09-07 | **2.1.1, build 20** (built 2026-11-01 by `make appstore APPSTORE_VERSION=2.1.1`) |

first submission of the 2.1 line. It carries everything in
[2.1.0.md](2.1.0.md), #214, and #228 to #251.

so the App Store version is released manually, the same day as the Mac
release.

sizes: [media.md](media.md).

## What's New - App Store, English

```
Long meetings, ready to read

A recorded meeting now reads like a document: paragraphs split at pauses,
chapters, and a reading bar that plays from any word. Jump between
chapters from their sheet or the scrubber on the edge. Summarize the
meeting into key points, decisions and actions, each with the moment it
was said, then share the note behind a link you can turn off.

Hermes, live

Follow a run as it happens, stop it or steer it mid-answer, and get an
alert when it ends. Approve or deny Hermes' sensitive commands right in
the chat. Tables, code and links read well on the iPhone.

Hermes scheduled tasks

See, run, pause and create Hermes tasks, no cron needed. Results arrive as
a notification from Hermes, with its face and name, and a tap opens the
task. A running task shows in the Dynamic Island.

Talk to your Hermes Agent

Run your own Hermes Agent? Link it with one QR code and talk to it from
the Chats tab. Send it photos, files and notes, and call its skills from
the + menu or by typing /.

Long recordings that finish

An hour-long recording now transcribes to the end. On-device
transcription keeps going with the screen locked on iOS 26, resumes after
a crash, and no longer loses or repeats words. Cloud uploads are smaller
and survive a lock.

A new way to capture

One composer for notes and chat. Type, or tap the mic: a voice capsule
records, transcribes and puts the text back where you were typing. If a
transcription fails, retry without losing the audio.

Also new

- Pick the model and reasoning level of the notes chat. Add a Claude API key in Settings > AI.
- A Whisper model download picks up where it stopped after you leave the app.
- Your notes slide aside like a card to reveal the menu, with native Liquid Glass on iOS 26.
- One + menu gathers tools, agents and connectors, with their live state.
- Installed agents are verified, and every action waits for your confirmation.
- The account screen shows your linked devices and Premium.
- Deleting a note you just recorded takes you back to the list.
```

## What's New - App Store, French

```
Les longues réunions, prêtes à lire

Une réunion enregistrée se lit comme un document : des paragraphes coupés
aux pauses, des chapitres, et une barre de lecture qui joue depuis

Suivez une exécution pendant qu'elle avance, arrêtez-la ou réorientez-la en
pleine réponse, et recevez une alerte quand elle se termine. Acceptez ou
refusez les commandes sensibles de Hermes dans le chat. Tableaux, code et
liens se lisent bien sur l'iPhone.

Les tâches planifiées de Hermes

Voyez, lancez, mettez en pause et créez des tâches Hermes, sans cron. Les
résultats arrivent en notification de Hermes, avec son visage et son nom,
et un toucher ouvre la tâche. Une tâche en cours s'affiche dans la Dynamic
Island.

Parlez à votre Hermes Agent

Vous avez votre propre Hermes Agent ? Liez-le avec un QR code et parlez-lui
depuis l'onglet Chats. Envoyez-lui photos, fichiers et notes, et appelez
ses skills depuis le menu + ou en tapant /.

Les longs enregistrements vont au bout

sont plus légers et résistent au verrouillage.

Un seul champ pour les notes et le chat. Tapez, ou touchez le micro : une
capsule vocale enregistre, transcrit et replace le texte là où vous
écriviez. Si une transcription échoue, relancez-la sans perdre l'audio.

- Choisissez le modèle et le niveau de réflexion du chat des notes. Ajoutez une clé API Claude dans Réglages > IA.

- Un seul menu + réunit outils, agents et connecteurs, avec leur état en direct.
- Les agents installés sont vérifiés, et chaque action attend votre confirmation.
- L'écran Compte montre vos appareils liés et Premium.
- Supprimer une note qu'on vient d'enregistrer ramène à la liste.
```

```
## FlowFlow 2.1.1 for Mac

**Update it with your iPhone.** 2.1.1 syncs with FlowFlow 2.1.1 on the
iPhone, and only with it: meeting summaries now sync, so both devices need
the same version.

### New
- Long meetings read as paragraphs and chapters, with a summary of key
  points, decisions and actions. Word highlight and jumps in the audio stay
  on the iPhone for now.
- Hermes: send it photos, files and notes, call its skills with `/`, follow
  a run live, stop it or steer it, approve its commands. Tables and code
  read well.
- Hermes scheduled tasks: see, run, pause and create them.
- Pick the model and reasoning level of the notes chat; add a Claude API
  key in Settings > AI.

### Fixed
- A cut Whisper model download resumes where it stopped.

Apple Silicon only. Download `FlowFlow-macos-arm64.dmg`, drag FlowFlow to
Applications.
```
