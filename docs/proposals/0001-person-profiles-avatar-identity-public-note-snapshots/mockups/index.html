Règles de vie du contenu partagé
  1. Chacun ne modifie ou supprime que ses propres notes dans un fil partagé.
  2. Supprimer sa note émet un signal via le backend : chaque téléphone la retire de sa base de connaissance (embeddings compris) pour s'aligner.
  3. Supprimer son compte ne supprime pas ses notes partagées : elles restent dans les fils.
  4. « Supprimer mes notes » les efface partout, chez tous les lecteurs ; à faire avant de supprimer le compte.
