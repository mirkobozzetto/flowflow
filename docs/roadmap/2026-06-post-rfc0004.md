## Reference: la re-sync est sure et idempotente

Conserve ici car operationnellement utile. Le re-sync ne casse rien (teste:
`notes_flow_both_directions_and_resync_is_idempotent`, la 2e session pousse 0,
applique 0). Chaque appareil ne pousse que ses lignes au-dessus du watermark du
pair; le merge par version vector rend le rejeu no-op; pas de duplication (cle =
entity_id + version_vector).

Precautions: meme version protocole des deux cotes, meme Wi-Fi + apps au premier
plan, pare-feu macOS autorisant les entrantes vers Flowflow.app, code
d'appairage a usage unique (ne pas recoller un vieux code).
